# Story 1.2: Design System and Initial Onboarding Screens

## Status

## Story

**As a** user,
**I want** to see a well-designed welcome screen and begin the quote process with postcode entry,
**so that** I can start getting a quote for motor insurance with a smooth, accessible user experience.

5. Autosave functionality stores postcode data
6. Screens are fully accessible (WCAG 2.2 AA compliant)
7. EN/BM language toggle is functional
8. Mobile-responsive layout works on all screen sizes

### Design Tokens

[Source: docs/ux-spec/5-design-tokens.md]

**Spacing Scale:**

- 4-pt system: 4, 8, 12, 16, 24, 32, 48

**Typography:**

- H1: 36px/44px line-height
- H2: 28px/36px line-height
- H3: 22px/30px line-height
- Body: 16px/24px line-height
- Small: 14px/20px line-height

**Border Radius:**

- 12px for cards
- 8px for inputs
- 999px for pills

**Elevation:**

- E0: flat (no shadow)
- E1: card elevation
- E2: modal elevation

**Motion:**

- Base: 160ms duration
- Enter: 240ms duration
- Standard/calm easing functions

**Color Roles:**

- Text: primary/secondary/inverse
- Background: canvas/surface
- Accent: brand colors
- States: success/warning/danger/info

**Focus:**

- 2px outline
- 2px offset
- High-contrast friendly
